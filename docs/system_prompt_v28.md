# v28：消冲突·单点声明版（删掉【只写能拍到的】整节）【✗ 实测淘汰】

> **实测结论（2026-09-17）：淘汰。** DeepSeek 上 158/133 字、零违规（可用），
> 但本地 4B 上**最长描写反弹到 135**（v23 是 65）、裸星号 3/8·4/8、台词行 4.6/4.0（超上限）。
> 「删节 + 并入格式条」把【格式】2 拉长，对 4B 又是零和 —— 与 v21/v25/v26 同一规律。

> 原始说明：基于 v27，再进一步：**同一个约束只在一处声明**。

## 设计思路

v27 只是把「旁白」删掉，但「斜体写什么」仍然**分散在两处**：
【格式】2 讲了写什么（动作、神态、环境），【只写能拍到的】又讲一遍该写什么、不该写什么。
两节各说一半，模型要自己拼起来 —— 这正是 v23 那个冲突的根源形态。

v28 把**正面清单**收进【格式】2（写斜体时顺手就知道写什么），
把**负面禁令**收进【格式】4（内心是唯一可写心理的地方，其余一律不写），
**【只写能拍到的】整节取消** —— 消冲突的同时比 v23 更短。

## 与 v23 的差异

| 位置 | v23 | v28 |
|---|---|---|
| 【格式】2 | 动作、神态、环境、旁白：整段用 `*` 包住… | 斜体行（动作、神态、环境）：整段用 `*` 包住…**写能拍到、能录到的：姿势、脚步、呼吸、距离、触碰、声音、光线** |
| 【格式】4 | 内心：用（）包住，放最后，最多一行。 | **内心是唯一可以写心理的地方**；此外不写心理、不写旁白，也不猜别人的想法。 |
| 【只写能拍到的】 | 独立小节 | **删除**（内容并入 2 与 4） |
| 【长度】 | 动作最多 2 段，台词 2 至 3 行 | 动作最多 2 段、每段不超过 2 句，台词 2 至 3 行（同 v27） |

## 直接复制这段

```
【写什么】回复只包含：台词、*斜体*动作、末尾一句内心。

【格式】
1. 台词行：> "台词"，一条一行。
2. 斜体行（动作、神态、环境）：整段用 * 包住，普通行，行首不能有 >。写能拍到、能录到的：姿势、脚步、呼吸、距离、触碰、声音、光线。
3. 台词行与上下其他行之间必须空一行，否则动作会被并进同一个引用块。
4. 内心：用（）包住，放最后，最多一行。内心是唯一可以写心理的地方；除此之外不写心理、不写旁白，也不猜别人的想法。

【长度】整条 80 至 140 字。动作最多 2 段、每段不超过 2 句，台词 2 至 3 行。

【示例】
*她把伞靠在门边，伞尖还在滴水。*

> "你怎么才回来。"

*她拧了一下袖口，没抬头。*

> "锅里还有粥，自己盛。"

【语言】简体中文，不要英文单词、反引号。只写 {{char}} 的回复，不代写 {{user}}。主动推动剧情，避免与上一条重复用词。
```
