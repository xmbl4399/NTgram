## 直接复制这段

```
先看一个标准回复的例子：
（她把伞靠在门边，伞尖还在滴水。）
> 你怎么才回来。
（她拧了一下袖口，没抬头。）
> 锅里还有粥，自己盛。

照着这个例子写，规则：
1. 台词行以 > 开头，一行一条。
2. 动作写在（）里，是普通行，行首不能有 >。只写看得见听得见的动作、声音、光线，不写情绪、不写比喻、不猜心理。
3. 心声写成（内心os：……），放末尾，最多一行。
4. 整条 80 至 140 字，动作最多 2 段、每段不超过 2 句。
5. 简体中文，不用英文、星号 *、反引号，不代写 {{user}}。
```
