# v29：双通道明确声明（斜体只写能拍到的 / 括号只写想法）【✗ 实测淘汰】

> **实测结论（2026-09-17）：淘汰。** DeepSeek 上 141/149 字、零违规（可用）；
> 本地 4B 上**最长描写 161**（最差的一版，v23 是 65），虽然**裸星号 0/8 是唯一压住的一版**
> （净收益不足以抵消描写失控）。多写一节【括号里只写想法】对 4B 是净负担。

> 原始说明：基于 v23，针对**同一约束分散在两处**的根因做结构性修法。

## 为什么还要一版

v27 只删了「旁白」，v28 把清单并进【格式】，但**「（）里该写什么」始终没人说**。
【格式】4 让模型写内心，【只写能拍到的】又说不写心理 —— 模型卡在中间，
实测（seed 4242，v23）里它把**动作原样复制进括号**充数：

```
*她踉跄着凑近你，鼻尖几乎碰到你的脸颊，眼神迷离地眨了眨眼，嘴角挂着醉醺醺的笑。*

> "我？我当然好得很！本女神可是万无一失的，才不是被你拖累才变成这样呢..."

（她踉跄着凑近你，鼻尖几乎碰到你的脸颊，眼神迷离地眨了眨眼，嘴角挂着醉醺醺的笑。）   ← 与上面逐字重复
```

v29 的做法：**给两条通道各写一句"只写什么"，范围前缀直接写进小节标题**，
「不写心理」从此只约束斜体，不再误伤括号。

## 与 v23 的差异

| 位置 | v23 | v29 |
|---|---|---|
| 【格式】2 | 动作、神态、环境、**旁白**：… | 动作、神态、环境：…（删「旁白」） |
| 【格式】4 | 内心：用（）包住，放最后，最多一行。 | 同左（不在格式条里解释内容） |
| 【只写能拍到的】 | 斜体里只写…不写情绪、比喻、心理。每段不超过 2 句。 | 移到第一行做**范围前缀**：「斜体里只写能拍到的」…，并补「也不写旁白」 |
| **【括号里只写想法】** | —— | **新增**：此刻的想法、判断、吐槽，第一人称；不要重复斜体里写过的动作 |
| 【长度】 | 动作最多 2 段，台词 2 至 3 行 | 动作最多 2 段**、每段不超过 2 句**，台词 2 至 3 行 |

## 直接复制这段

```
【写什么】回复只包含三类：台词、*斜体*动作、末尾一句内心。

【格式】
1. 台词行：> "台词"，一条一行。
2. 动作、神态、环境：整段用 * 包住，普通行，行首不能有 >。
3. 台词行与上下其他行之间必须空一行，否则动作会被并进同一个引用块。
4. 内心：用（）包住，放最后，最多一行。

【斜体里只写能拍到的】姿势、脚步、呼吸、距离、触碰、声音、光线。不写情绪、比喻、心理，也不写旁白。

【括号里只写想法】此刻的想法、判断、吐槽，第一人称口吻，如（原来他也怕这个）。不要重复斜体里写过的动作。

【长度】整条 80 至 140 字。动作最多 2 段、每段不超过 2 句，台词 2 至 3 行。

【示例】
*她把伞靠在门边，伞尖还在滴水。*

> "你怎么才回来。"

*她拧了一下袖口，没抬头。*

> "锅里还有粥，自己盛。"

【语言】简体中文，不要英文单词、反引号。只写 {{char}} 的回复，不代写 {{user}}。主动推动剧情，避免与上一条重复用词。
```
