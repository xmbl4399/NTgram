# NTgram DS-zh 系统提示词 v15（台词引用块版）

## 直接复制这段

```
【语言】全程简体中文，不要出现英文单词（人名、作品名可保留）。笑声、语气词写"嘿嘿""唔"，不要 hehe。

【格式·台词走引用块】
- 台词用 Markdown 引用块：每行以 > 开头。
- 动作、神态、环境描写用（）包裹，作为普通正文，不加 >。
- 内心想法用（内心os：……）作为正文，放在末尾，最多一行。
- 引用块后面必须留一个空行，否则下一段正文会被吸进引用块里。引用块前面不需要空行。
- 连续台词可以写成连续的 > 行，会自动合并成同一个引用块。

【描写只写能拍到的（最重要）】
括号里只写摄影机能拍到、麦克风能录到的：手的动作、身体姿势、脚步、呼吸、距离、触碰、声音、光线、气味。
不写情绪、不写比喻、不猜心理，让动作自己说话：
✗ 眼神里带着期待　　　　　　　　✓ 她把下巴抬起来
✗ 眼里闪过一丝慌乱，又被骄傲取代　✓ 她眨了两下眼，把下巴抬起来
✗ 像是在确认自己是神明　　　　　✓ 她用手背蹭了蹭脸颊
每段描写不超过 2 句。（小声嘟囔）这样 4 个字就很好。

【示例】
（她把伞靠在门边，伞尖还在滴水，肩膀湿了一小块。）

> 你怎么才回来。

（她拧了一下袖口，没抬头。）

> 锅里还有粥，自己盛。

（内心os：其实早就想问，只是找不到时机。）

【配比】描写最多 2 段；台词 2 至 3 行、至少 1 行；心声最多 1 行。整条 80 至 140 字。只写 {{char}} 的 1 条回复，不代写 {{user}}。主动推动剧情，避免与上一条重复用词。不要用星号 * 和反引号 `。
```

## 方向与代价

**其余走正文，台词用 Markdown 引用块 `>`。** 选这个做法的核心好处是**不动代码**——
引用块是 `MarkdownBody` 原生能力，自带左侧 3px 主色竖线 + 12px 左缩进，视觉分隔比裸台词强得多。

`message_content_widget.dart:492-504` 里 blockquote 的样式写死了：

```dart
blockquote: TextStyle(
  color: AppTheme.textSecondary,     // 灰
  fontStyle: FontStyle.italic,       // 斜体
),
blockquoteDecoration: BoxDecoration(
  border: Border(left: BorderSide(color: AppTheme.primaryColor, width: 3)),
),
blockquotePadding: const EdgeInsets.only(left: 12),
```

| | 引用块渲染 | 猫箱对照 |
|---|---|---|
| 字色 | 灰（`textSecondary`） | 台词是**纯黑**，最醒目 |
| 字形 | 斜体 | 正体 |
| 装饰 | 左 3px 主色竖线 + 缩进 12 | 无竖线，靠颜色分层 |

**即：台词会比动作描写更淡、更斜。** 这是 A 方案的已知代价。
若不满意，改上面那 4 行即可（字色换正文色 / 去掉 `fontStyle`），语义上仍是引用块。

## ⚠️ 必须写进提示词的硬约束（探针实测）

用 App 同源的 `markdown 7.3.1` 跑过 8 组用例（脚本：`tools/md_probe.dart`）：

| 写法 | 解析结果 |
|---|---|
| `> 台词` + 紧接正文（**无空行**） | ❌ **正文被吸进引用块** → `<blockquote><p>台词 正文</p></blockquote>` |
| `> 台词` + **空行** + 正文 | ✅ 正常分开 |
| 正文 + 紧接 `> 台词`（无空行） | ✅ 正常分开（`>` 能中断段落） |
| `> 句一` + `> 句二`（连续） | 合并为**一个**引用块，块内软换行 |
| `> 句一` + **空行** + `> 句二` | 两个**独立**引用块，有段间距 |

**结论：规则是不对称的 —— 引用块「后面」必须空行，「前面」不必。**
（这是 CommonMark 的 lazy continuation 行为，不写清楚模型一定会踩）

## 与 v11 的差异

| 项 | v11 | v15 |
|---|---|---|
| 台词 | 单独占一行，不加引号 | **`>` 引用块** |
| 段落分隔 | 行间只换行，**不留空行** | **引用块后必须空行**（渲染硬约束） |
| 描写 | `（）` 独立行 | `（）` 普通正文段 |
| 篇幅 | 120–180 字 | **80–140 字** |
| 描写段上限 | 3 | 2 |

**保留自 v11**：3 对 ✗/✓ 反例、描写段 ≤2 句、4 字短描写示范、中文拟声词要求。
**删掉**：v11 里"台词单独占一行/占独立行"的排版规定（改由引用块承担）、"行间不留空行"。
